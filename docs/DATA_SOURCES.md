# AeroTurn: datasets, sources and assumptions

**Summary:**
- The brief provides **no dataset** and asks teams to synthesise their own.
- All operational data in AeroTurn (passengers, bags, crew, flights, defects) is **synthetic and byte-reproducible** (seed 812).
- Every rule, threshold and legal amount in the code either comes from a **public source cited below** or is listed under **[Our assumptions](#4-our-assumptions-no-external-source)**.

### What is real and what is synthetic

| Element | Real or synthetic | Source / notes |
|---|---|---|
| Scenario: EK-812 75 min late, crew 20 min from the duty limit, hydraulic defect, 280 connecting, 45 misconnecting | **From the problem statement** | Domain 4 brief |
| Airport codes, names, cities, countries, EU membership | **Real** public facts | e.g. [OurAirports open data](https://ourairports.com/data/) (public domain) |
| Airport coordinates | **Real-world reference values**, entered by hand, accurate to about 1 km | Used only to compute great-circle distance for EU261 bands. The closest any destination comes to a band edge is **101 km** (Larnaca–Karachi, 3,399 km against the 3,500 km edge), so a 1 km error cannot change any compensation amount. Cross-check: [OurAirports](https://ourairports.com/data/), [airports.csv](https://github.com/davidmegginson/ourairports-data) |
| Other flight numbers, times, gates, loads | **Synthetic** | Plausible DXB bank; not a real timetable |
| Partner carrier "IP" | **Fictional** | |
| Aircraft A6-EQX, seat maps | **Illustrative** | Generic 777-300ER / A380 / 777-200LR / A350 layouts, not any airline's real cabin |
| Passenger names | **Synthetic** | Random combinations of common first and last names; contacts use the reserved `example.com` domain |
| Special Service Request codes (UMNR, WCHR, WCHS, WCHC, MEDA, BLND, DEAF, DPNA, INFT) | Industry-standard codes | `PREG` is our own label |
| Bag tags `0176xxxxxx` | **Synthetic** | 10-digit licence-plate style |
| Crew rosters and duty clocks | **Synthetic** | Chosen to recreate the brief's situation exactly (the inbound crew's limit of 15:40 comes from the FDP table below) |
| Tech-log entries and MEL references | **Synthetic / illustrative** | |
| Turnaround task durations | **Our estimates** | See assumptions |

The brief suggests OpenSky and OurAirports. We use OurAirports-style airport reference data. OpenSky flight tracks are not needed, because the scenario is one defined disruption, not a historical replay.

## 2. Rules implemented in code, and their public sources

### Flight-time limitations (crew duty)

| Rule in `aeroturn/guards.py` | What we implemented | Source |
|---|---|---|
| Maximum daily FDP | The EASA table for acclimatised crew: 13:00 for an FDP starting 06:00–13:29 with 1–2 sectors, the published bands for other start times, −30 min per extra sector, 9:00 floor | EASA ORO.FTL.205(b)(1), Table 2: [UK CAA regulatory library copy of Reg. 965/2012](https://regulatorylibrary.caa.co.uk/965-2012/Content/Regs/05130_ORO.FTL.205_Flight_duty_period_FDP.htm) |
| Standby | FDP counts from reporting. Airport standby beyond 4h reduces the maximum FDP, and airport standby + FDP ≤ 16h. Home standby beyond 6h reduces the maximum FDP | CS FTL.1.225: [CAA library](https://regulatorylibrary.caa.co.uk/965-2012/Content/AMC/CS%20FTL%201%20225%20Standby.htm); EASA FAQs [47632](https://www.easa.europa.eu/en/faq/47632), [47631](https://www.easa.europa.eu/en/faq/47631), [47642](https://www.easa.europa.eu/en/faq/47642), [47643](https://www.easa.europa.eu/en/faq/47643); ORO.FTL.225: [CAA library](https://regulatorylibrary.caa.co.uk/965-2012/Content/Regs/05170_ORO.FTL.225_Standby_and_duties_at_the_airport.htm) |
| Minimum rest | At least 12h before duty | ORO.FTL.235(a)(1), at home base: the greater of the preceding duty or 12h. [CAA library](https://regulatorylibrary.caa.co.uk/965-2012/Content/Regs/05190_ORO.FTL.235_Rest_periods.htm) |
| Minimum cabin crew | 1 cabin crew per 50 seats | ORO.CC.100(b)(2), the fallback calculation. In reality the aircraft's certified minimum governs: [EASA FAQ](https://www.easa.europa.eu/en/the-agency/faqs/minimum-required-cabin-crew) |
| Fatigue report is absolute; commander's discretion is never planned | Policy floor | Our design choice. The regulation allows discretion only for unforeseen circumstances |

**Fidelity note:** this is a simplified model, not a certified implementation of UAE GCAA CAR-OPS. It omits FRM tables, extensions, in-flight rest and cumulative limits.

### Maintenance

| Rule | What we implemented | Source |
|---|---|---|
| Dispatch-blocking deferred defect needs a Certificate of Release to Service (CRS) | MX-001 blocks departure while the item is open | Standard airworthiness practice; the MEL entries are illustrative |
| Licence category | A hydraulic (mechanical, ATA 29) item needs a **B1** engineer type-authorised on the aircraft, so a B2 (avionics) signature is refused | EASA Part-66 licence categories and privileges: [EASA FAQ](https://www.easa.europa.eu/en/the-agency/faqs/privileges-part-66-licence). The ATA→licence mapping table is our simplification |
| CRS timing | A CRS cannot be signed before the inspection can have finished (MX-003) | Our logic |

### Passengers and bags

| Rule | What we implemented | Source |
|---|---|---|
| A bag never travels without its passenger (PPBM) | DB trigger, deferred foreign key and guard BAG-001 | ICAO Annex 17 passenger/baggage reconciliation (Standard 4.5.3, renumbered 4.5.6 in 2022): [IATA Hold Baggage Reconciliation (2025)](https://www.iata.org/contentassets/1998554ac6624b97a2de8418938eaade/2025-hold-baggage-reconciliation-iata2025.pdf) |
| EU261 compensation amounts | €250 (≤1,500 km), €400 (≤3,500 km), €600 (>3,500 km); halved for >3,500 km when arrival is 3–4h late | Reg. (EC) 261/2004 Art. 7: [text](https://www.legislation.gov.uk/eur/2004/261/article/7); reduction thresholds: [European Parliament factsheet](https://www.europarl.europa.eu/erpl-app-public/factsheets/pdf/en/FTU_2.2.3.pdf) |
| Long delay = compensation | Arrival delay of 3h or more | CJEU C-402/07 *Sturgeon*: [judgment](https://mansfield.bailii.org/eu/cases/EUECJ/2009/C40207.html) |
| Measured at the final destination, whole journey from the EU | Compensation follows the final-arrival delay of the single-booking journey that started in Larnaca | CJEU C-11/11 *Folkerts*; CJEU C-537/17 *Wegener*: [CURIA press release](https://curia.europa.eu/jcms/upload/docs/application/pdf/2018-05/cp180077en.pdf); applied to an Emirates connection via Dubai in *Gahan v Emirates* [2017] EWCA Civ 1530: [judgment](https://caselaw.nationalarchives.gov.uk/ewca/civ/2017/1530) |
| Right to care | Meals for long waits, hotel when overnight | Reg. 261/2004 Art. 9: [text](https://www.legislation.gov.uk/eur/2004/261/article/9) |
| Free tickets excluded | Lap infant assumed to travel free | Art. 3(3): [text](https://www.legislation.gov.uk/eur/2004/261/article/3) |
| EU261 does not cover EK-813 | A DXB departure on a non-EU carrier | Art. 3(1) scope (same link) |

### Delay cost

| Value | Ours | Public reference |
|---|---|---|
| Aircraft tactical delay cost | €100/min plus €0.40 per passenger-minute, as an **illustrative assumption** | The EUROCONTROL / University of Westminster reference values are the standard European source: [EUROCONTROL, cost of one minute of delay](https://www.eurocontrol.int/publication/evaluating-true-cost-airlines-one-minute-airborne-or-ground-delay); [Westminster, cost of delay to air transport in Europe](https://westminsterresearch.westminster.ac.uk/item/90w7x/the-cost-of-delay-to-air-transport-in-europe-quantification-and-management). EUROCONTROL's Standard Inputs are reported at about €166/min at gate for tactical delay, so our figure is conservative |

## 4. Our assumptions (no external source)

These are modelling choices. They are listed so judges can challenge them, and they can all be edited in `aeroturn/config.py` or `aeroturn/guards.py` (the latter requires re-pinning).

| Assumption | Value | Why |
|---|---|---|
| Base minimum connection time (MCT) | 60 min | Generic international-to-international transfer. DXB's published MCT is not used |
| Extra MCT for reduced mobility / medical / unaccompanied minor / remote stand | +20 / +20 / +15 / +25 min | Assistance and escort hand-over take longer |
| Bag transfer minimum | 45 min | |
| Unaccompanied minor protection | Home carrier only, no departure after 22:00, wait ≤ 8h | Typical airline UMNR policy |
| Priority tiers P1–P4 | Defined in `guards.pax_tier` | Brief requires vulnerable-passenger priority protection |
| Exit-row eligibility | No UMNR, reduced-mobility, medical, pregnant or infant passengers; age 15–74 | Typical exit-row policy |
| Connection hold | Suggest only if ≤ 15 min and cheaper than rebooking; network cap 30 min | |
| Meal voucher / hotel | €25 / €150 per passenger | |
| Rotation buffer at CDG | 30 min | Used for the knock-on delay |
| Standby call-out response / report-before-off-blocks | 10 min / 45 min | |
| Turnaround task durations | e.g. deplaning 25, cleaning 30, catering 35, hydraulic inspection 55, boarding 35 min | Estimates for a 777 turn |
| Stand taxi times | B14 6, C31 8, R205 11 min | |

## 5. How a judge can check all of this

```powershell
python scripts/build_dataset.py    # regenerates byte-identical data from seed 812
python -m pytest -q                # 60 tests incl. reproducibility, guards, rollback, HITL
python run_demo.py --yes           # full scenario in the terminal with every verdict printed
```

`aeroturn/guards.sha256` pins the exact guard code that produced these results.
